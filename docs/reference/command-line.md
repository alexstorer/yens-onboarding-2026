# Command Line

Everything on this page lives in our longer
<a href="https://gsbdarc.github.io/gsb-research-computing-ai-skills/" target="_blank" rel="noopener noreferrer">research computing course</a>,
which teaches the shell properly and at a pace you set. Rather than keep a second copy
here — one that would drift out of step with it — this page is a map into it.

Nothing here is a prerequisite for this course. Reach for it when a command on one of the
lab pages does something you did not expect, or when you want the ground underneath what
you have been copying and pasting.

| Understand how a cluster's storage is laid out, and which directory to put a thing in | <a href="https://gsbdarc.github.io/gsb-research-computing-ai-skills/day1/cartographers-room/" target="_blank" rel="noopener noreferrer">The Cluster File System</a> |
| Log in to a remote machine over SSH, and understand what that connection is | <a href="https://gsbdarc.github.io/gsb-research-computing-ai-skills/day1/ssh-gate/" target="_blank" rel="noopener noreferrer">Connecting to a Cluster</a> |
| Copy files between your laptop and a cluster with `scp` | <a href="https://gsbdarc.github.io/gsb-research-computing-ai-skills/day1/scroll-transfer/" target="_blank" rel="noopener noreferrer">Transferring Files (scp)</a> |

{: .tip }
> The quickest way to stop guessing at a command is to ask Claude Code what it does before
> you run it — `> what does this command do, and what would it change?` — and to lean on
> <kbd>Tab</kbd> completion, which will not complete a path that does not exist.
